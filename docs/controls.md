# VOXEL HAULER: ASPHALT RETALIATION
## Vehicle Controls & Gameplay Guide

### Primary Driving Controls
| Action | Key / Input | Description |
| :--- | :--- | :--- |
| **Accelerate** | `W` or `Up Arrow` | Applies throttle to the semi-truck powertrain (Top speed: 105 MPH) |
| **Brake / Reverse** | `S` or `Down Arrow` | Applies heavy pneumatic service brakes; reverses when stopped |
| **Steer Left** | `A` or `Left Arrow` | Smooth steering input with speed-sensitive turning inertia |
| **Steer Right** | `D` or `Right Arrow` | Smooth steering input with speed-sensitive turning inertia |
| **Recover Vehicle** | `R` | Resets truck position and upright rotation if flipped or stuck |

### Retaliation Combat Controls
| Action | Key / Input | Description |
| :--- | :--- | :--- |
| **Activate Retaliation** | `Spacebar` | Deploys dual roof-mounted turrets when Rage Meter is at 100% |
| **Fire Turrets** | `Left Mouse Button` | Discharges rapid twin arcade projectiles at the selected target |
| **Cycle Targets** | `Tab` | Cycles through candidate traffic/police targets in forward arc |

### Camera & System Controls
| Action | Key / Input | Description |
| :--- | :--- | :--- |
| **Cycle Camera Distance** | `C` | Toggles between close chase and wide cinematic follow distance |
| **Pause Game** | `Escape` | Opens Pause Menu with options to Resume, Restart, Settings, or Exit |

### Garage Controls
| Action | Key / Input | Description |
| :--- | :--- | :--- |
| **Previous Truck** | `A` / `Left Arrow` / UI Button | View previous truck color variant |
| **Next Truck** | `D` / `Right Arrow` / UI Button | View next truck color variant |
| **Rotate Preview** | `Mouse Drag` or `Q`/`E` | 360-degree turntable camera rotation around truck |
| **Start Delivery** | `Enter` / `Space` / UI Button | Confirms truck selection and begins the delivery mission |
